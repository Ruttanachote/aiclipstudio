Privacy Policy

Effective 29 October 2026

AI Clip Studio ("the app") is a desktop application that runs on the user's own Windows computer. This policy explains what data the app handles when it is connected to TikTok and other services.

Data the app accesses

  • TikTok basic profile (scope user.info.basic): open ID, display name and avatar, used only to show which account is connected.
  • TikTok posting (scopes video.upload, video.publish): used only to upload videos the user created in the app and chose to publish, with the caption and privacy setting the user chose.
  • Access and refresh tokens issued by TikTok, used only to make the requests above.

Where data is stored

All data, including TikTok tokens, videos and captions, is stored only in the app's folder on the user's own computer. The app has no server and no user database. The developer does not receive, collect or have access to any user data.

Sharing

The app does not sell, rent or share data with anyone. Data is sent only to the service it belongs to (for example, videos are sent to TikTok when the user publishes them). The app contains no advertising and no analytics or tracking.

Retention and deletion

Data stays on the user's computer until the user removes it. To delete it, disconnect TikTok in the app's Settings (which deletes the stored tokens) or delete the app's data folder. Access can also be revoked at any time in the TikTok app under Settings and privacy → Security → Manage app permissions.

Children

The app is not directed at children under 13 and is not intended for use by them.
